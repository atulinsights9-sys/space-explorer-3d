# NIKSYNC Space Explorer

Interactive 3D Solar System that runs in the browser: rotate, zoom, pick a date (1800-2050), guided tours, Earthrise, photo mode.

## Files
- `index.html`: the whole explorer (single file, textures embedded)
- `about.html`, `privacy.html`, `terms.html`, `contact.html`, `404.html`: site pages
- `robots.txt`, `sitemap.xml`: replace `REPLACE-WITH-YOUR-SITE` with your real address

## Deploy
No build step. Publish the repository root (Netlify: leave the build command empty).
